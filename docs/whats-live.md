# What's live: NZC AI and NZC Portal

The marketing team reads this before claiming any capability publicly. Only
claim something as available if its status below is **Live**.

What each status means:

- **Live**: released and available to customers today.
- **In beta**: available to named users or pilot clients only. Not for public claims.
- **Coming soon**: built or being built, but no customer can use it yet.
- **Removed**: was available, no longer is. Stop mentioning it.

---

## Log (newest first)

### 13 October 2026: four NZC Portal apps confirmed live

- **Product:** NZC Portal: EPC and MEES App, ESOS App, SECR App, Energy Policy App
- **Feature:** EPC and MEES App; ESOS App; SECR App; Energy Policy App
- **Status:** Live
- **What a user can do today:** Customers can use all four apps now. A one-line description of what each app lets a user do is still to be confirmed. Until it is, say only that the app is available, and do not claim any specific capability within it.
- **Limits or caveats:** Limits for each app are still to be confirmed. The "SECR reporting readiness check" listed below is still Coming soon; do not present it as part of the live SECR App.

### 11 October 2026: status review of everything built so far

- **Product:** NZC Portal and NZC AI (all features below)
- **Feature:** Status review
- **Status:** Coming soon, for the features listed below as Coming soon
- **What a user can do today:** None of the features covered by this review can be used by customers yet. They are built and tested, but not released. (This review did not cover the four live NZC Portal apps; see the 13 October entry.)
- **Limits or caveats:** Do not describe any feature below as available, launched or live until this log moves it to Live. There is no Landlord, Client or Microgeneration app in the portal yet; those names should not be used as if they exist.

### 10 October 2026: client data feed (API keys)

- **Product:** NZC Portal
- **Feature:** Client data feed into Power BI, Excel or a data warehouse
- **Status:** Coming soon
- **What a user can do today:** Once released, a client will be able to pull their own buildings' energy, carbon and assessment results into their own reporting tools on a schedule, using a private key that only sees their buildings.
- **Limits or caveats:** Read-only. Keys are set up by the NZC team, not self-service. Covers buildings and portfolio figures only, not transport, value chain or SECR summaries.

### 12 September 2026: NZC AI calculation tools

- **Product:** NZC AI
- **Feature:** AI assistant tools for carbon intensity, emission factors, CRREM and UK NZCBS
- **Status:** Coming soon
- **What a user can do today:** Once released, an AI assistant will be able to work out a building's energy and carbon intensity, look up UK government emission factors, find the year a building falls off its CRREM pathway, and run an indicative check against the UK Net Zero Carbon Buildings Standard.
- **Limits or caveats:** UK government emission factors only. The UK NZCBS check is indicative, not certification; certification needs an approved verifier. CRREM and UK NZCBS figures depend on licensed reference data being loaded.

### 12 September 2026: Scope 3 analysis

- **Product:** NZC Portal
- **Feature:** Scope 3 year-on-year trend, category completeness, hotspots, targets and supplier submission links
- **Status:** Coming soon
- **What a user can do today:** Once released, a user will be able to compare Scope 3 like-for-like year on year, show that all fifteen categories have been considered, see which suppliers carry the most emissions, track progress against a target, and send suppliers a one-time link to submit their own figures.
- **Limits or caveats:** The hotspot view is a spend-based screen and never feeds a reported total. Supplier submissions are reviewed before they count.

### 10 September 2026: reporting features

- **Product:** NZC Portal
- **Feature:** Portfolio roll-up, CRREM and UK NZCBS assessment, transport and travel, refrigerants/water/waste, spreadsheet import, reporting readiness, value chain and inbound data requests
- **Status:** Coming soon
- **What a user can do today:** Once released, a user will be able to see energy and carbon across a portfolio for any reporting period, record fleet, travel, refrigerants, water and waste, import spreadsheets, check what is missing before a SECR return, manage supplier and customer emissions data, and answer customers' data requests from the portal's own figures.
- **Limits or caveats:** UK reporting (SECR, UK government factors). CRREM and UK NZCBS results are indicative and depend on licensed reference data.

### 9 September 2026: data foundations

- **Product:** NZC Portal
- **Feature:** Smart-meter data, consents, building register, environmental screening and external data sources
- **Status:** Coming soon
- **What a user can do today:** Once released, a user will be able to pull half-hourly smart-meter data for a building with the occupier's consent, record and renew those consents, register buildings and link meters, and screen a location for flood, ground, air quality and other risks in one click.
- **Limits or caveats:** Smart-meter data is UK only and needs the occupier's written consent first. Live smart-meter data needs the supplier account to be switched on for live use. Some data sources need paid licences or keys before they work.
